Ready for your first commit? Start here.

With Git installed, open a terminal in your project folder. Create or edit a file, then run these commands. If this folder already has a Git repository, skip git init.

git init
git status
git add .
git commit -m "My first commit"

If Git asks for your identity, set your name and email with git config --global user.name "Your Name" and git config --global user.email "you@example.com", then retry the commit. Only stage files you intend to track; keep passwords and secrets out of your repository.
